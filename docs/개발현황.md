# 서천군 정책관리 ERP — 개발 현황

> 기준: `docs/ERP_기능_체크리스트.json` · 진행 상태는 매 작업 종료 시 훅(`scripts/checklist.mjs`)으로 자동 동기화

## 요약

| 상태 | 개수 |
|------|------|
| ✅ 완료(done) | 64 |
| ⏸ 보류(hold) | 5 |
| ⬜ 예정(todo) | 6 |
| **합계** | **75** |

## 완료된 단계 (1~6단계 핵심 기능 전부)

- **1단계 기반** — 로그인/세션, 3단계 RBAC, 미들웨어 보호, 부서·팀·읍면·공통코드
  기준정보, 사용자/기준정보 관리, 감사 로그, 내 정보·비밀번호 변경
- **2단계 정책·협업** — 정책 아카이브(시행/구상, 분류·검색·필터), 상태 전환 이력,
  정책별 의견, 분야별 사업제안(추천·검토상태)
- **3단계 주요업무 보고회** — 13개 입력항목, 회차(2·7·11월) 스냅샷,
  향후계획 대비 추진현황 변경 추적
- **4단계 순기표** — 분기(1·4·7·10월) 전 사업, 정책적 주요사업 ★지정,
  부서/읍면/종료연도별 별도 관리, 변경 추적
- **5단계 기획실 연계** — 공약 이행(계층·이행률), 국도비 공모(단계·재원매칭·투자심사),
  인구·지방소멸(읍면 배분·집행률), 성과관리(목표·실적·달성률)
- **6단계 대시보드·출력·알림** — 분야/읍면/재원별 사업비·공약·공모 지표,
  업무 일정(D-day), CSV 출력, 인쇄/PDF 출력, 첨부(위치도·현장사진) 미리보기

## 보류(hold) — 외부 의존/운영 환경 필요

| 항목 | 사유 / 대안 |
|------|-------------|
| HWP(한글) 보고서 출력 (F13-01) | 한글(HWPX) 생성은 별도 상용 엔진·라이선스 필요. 현재 **인쇄/PDF + 엑셀(CSV)** 로 대체. 군 표준 양식 확정 후 도입 검토 |
| 읍면 지도 시각화 (F15-06) | 서천군 행정경계 GeoJSON 확보 후 적용. 현재 읍면별 **막대그래프**로 대체 |
| 정기 백업·복구 절차 (F16-04) | 앱 코드가 아닌 **운영(DBA/인프라) 절차**. PostgreSQL `pg_dump`/PITR 표준으로 수립 |
| 배포 환경 (F17-03) | 군청 내부망 서버 사양·보안 정책 확정 후 진행(컨테이너/단일서버) |
| 사용자 매뉴얼·관리자 가이드 (F17-05) | UI 안정화 후 작성. README에 운영 기본 안내 포함 |

## 실행 방법

```bash
pnpm install
cp .env.example .env      # DATABASE_URL, AUTH_SECRET
pnpm db:migrate && pnpm db:seed
pnpm dev                  # http://localhost:3000  (admin / admin1234)
```
