# 서천군청 정책관리 ERP 시스템 — 목표문서 (요구사항 정의서)

> **문서 성격**: 시스템 구축에 앞서 도입 목표와 요구사항을 정리한 종합 기획·요구사항 문서
> **대상 조직**: 충청남도 서천군청 (기획실/각 부서 기획팀 중심)
> **작성일**: 2026-05-30
> **버전**: v0.2 (서천군 기획실 맞춤 보강)

---

## 1. 문서 개요

### 1.1 목적
본 문서는 서천군청 각 부서 기획팀과 **기획실**이 시행 중·구상 중인 정책을 한곳에 모아
공유·논의하고, **주요업무 보고회·순기표**를 체계적으로 관리하며, **군수 공약사업·국도비
공모사업·지방소멸대응기금 사업·성과관리**까지 연계해 데이터 기반의 정책 판단을 지원하는
**내부 정책관리 ERP 시스템**의 도입 목표와 요구사항을 정의한다. 이해관계자 공유·보고와
향후 개발 착수의 기준 자료로 동시에 활용한다.

### 1.2 대상 독자
- 의사결정자(군수·부군수·기획실장 등 승인 라인)
- 시스템 도입 담당자(관리자), 기획실 정책/평가 담당
- 실제 사용 부서(각 부서 기획팀, 부서 **서무**)
- 개발/구축 담당자(외주 또는 내부)

### 1.3 용어 정의
| 용어 | 정의 |
|------|------|
| 정책(시행정책) | 현재 서천군에서 시행되고 있는 정책 |
| 정책(구상정책) | 아직 시행 전, 구상·검토 중인 정책 아이디어 |
| 유형화(분류) | 정책·사업을 분야/성격에 따라 카테고리로 구분하는 것 |
| 분야 | 정책이 속하는 행정 분야(복지·농업·수산·관광·인구 등) |
| 사업 성격(유형) | 투자사업/행사·축제/제도·시책/보조사업/경상사업 등 |
| 주요업무 보고회 | 연 3회(2·7·11월) 개최, 부서별 주요사업을 보고·관리 |
| 순기표 | 분기 1회(1·4·7·10월) 작성, 서천군의 **모든 사업**을 관리하는 표 |
| 정책적 주요사업 | 순기표 사업 중 정책적으로 중요하다고 판단해 별도 관리하는 사업 |
| 공약사업 | 군수 공약을 이행하기 위한 단위사업(이행관리 대상) |
| 공모사업 | 중앙부처·도 등에서 공모하는 국도비 지원사업(신청·선정 관리) |
| 재원구분 | 사업비의 출처 구분: 국비/도비/군비/기타(기금·민자 등) |
| 지방소멸대응기금 | 인구감소지역 대응을 위한 정부 기금 사업 |
| 성과지표 | 사업·시책의 목표치와 실적을 측정하는 지표 |
| 서무 | 각 부서에서 주요업무·순기표 입력을 담당하는 직원 |
| 읍면 | 서천군 내 행정구역 단위(지역별 분석 기준) |

## 2. 추진 배경 및 목표

### 2.1 서천군 정책 환경 (기획 관점)
- 서천군은 **인구감소지역**으로 지정되어 **지방소멸 대응**과 **인구정책**이 군정의
  핵심 과제이며, **지방소멸대응기금** 등 외부 재원 활용·관리가 중요하다.
- 국립생태원·국립해양생물자원관·서천갯벌(세계자연유산)·한산모시(인류무형문화유산) 등
  **생태·문화 특화 자원**을 활용한 관광·지역개발 사업이 많아 **유형·지역(읍면)별 관리**
  필요성이 크다.
- 군 재정 여건상 **국비·도비 공모사업** 확보와 **투자심사·중기재정계획**과의 연계가 중요하다.

### 2.2 현황 및 문제점
- 시행·구상 정책이 부서별로 흩어져 **전체 현황 파악이 어렵다.**
- 정책 의견을 상시 모으고 검토할 **협업 채널이 부재**하다.
- 주요업무·순기표·공약·공모사업 자료를 **수기(한글/엑셀)로 중복 취합**하여 시간이 많이 들고,
  회차·분기 간 **변경·진행 추적**이 어렵다.
- 사업비·재원·지역 분포 등 **데이터 기반 판단 근거**가 부족하다.

### 2.3 도입 목표
1. **정책·사업 통합 관리**: 시행·구상 정책과 모든 사업을 유형/분야/읍면/재원별로 분류·검색.
2. **상시 협업·의견 수렴**: 정책별 의견·분야별 사업 제안으로 집단지성 활용.
3. **보고 업무 디지털화**: 주요업무·순기표를 표준 양식으로 입력하고 회차/분기 변경 자동 추적.
4. **기획실 핵심업무 연계**: 공약사업 이행·국도비 공모사업·지방소멸대응기금·성과관리 통합.
5. **데이터 기반 의사결정**: 유형·지역·재원별 사업비, 공약 이행률 등 지표를 대시보드로 시각화.
6. **권한 기반 운영**: 로그인·권한 체계로 정보 보안과 업무 책임 명확화.

### 2.4 기대효과
| 구분 | 기대효과 |
|------|----------|
| 정성적 | 정책 가시성·협업 향상, 보고 자료 표준화, 공약·공모·기금 관리 일원화 |
| 정량적 | 보고회·순기표·공약 점검 취합 시간 단축, 중복 입력·변경 누락 감소, 국도비 확보 관리 효율화 |

## 5. 기능 요구사항

### 5.1 정책 아카이브 (시행 중 / 구상 중 정책)
- **상태 구분**: `시행정책` / `구상정책`.
- 입력 항목(예): 정책명, 상태, **유형(성격)·분야 분류**, 담당 부서·팀, 작성자, 요약,
  상세 내용, 관련 사업비·재원(선택), 기간(선택), 읍면(선택), 첨부자료.
- **분류·검색·필터**: 시행/구상을 각각 유형·분야·부서·읍면·기간으로 분류해 열람,
  키워드 검색·다중 필터, 목록/카드 보기.
- 구상정책 → 시행 전환 시 상태 변경 및 이력 기록. (필요 시 공약·공모사업과 연결)

### 5.2 의견 · 아이디어 (협업)
- **정책별 자유 의견**(댓글), **분야별 사업 제안** 게시판("어떤 분야에 어떤 사업이 좋을지"),
  **추천/공감**으로 군에 도움이 될 정책 식별.
- 작성자/부서 표시, 정렬(최신/추천순), 분야별 모아보기, 채택/검토 상태 표시.

### 5.3 주요업무 보고회 관리 (연 3회: 2월 · 7월 · 11월)
부서 **서무**가 표준 양식으로 사업을 입력·관리한다.

**입력 항목**
| # | 항목 | 비고 |
|---|------|------|
| 1 | 부서명 | 공통코드 |
| 2 | 팀명 | 공통코드 |
| 3 | 사업명 | |
| 4 | 목표 및 방향성 | |
| 5 | 사업비 | 재원별(국/도/군/기타) 분리, 단위(천원) |
| 6 | 사업기간 | 시작~종료(연도 포함) |
| 7 | 사업위치 | **읍면 코드 연계** |
| 8 | 사업내용 | |
| 9 | 추진현황 | 진행 상태/진행률 |
| 10 | 향후계획 | 다음 회차 추적 기준 |
| 11 | 문제점 및 해결방안 | |
| 12 | 기대효과 | |
| 13 | 참고자료 | **위치도·현장사진 등 이미지 첨부** |

**회차별 변경 추적**
- 회차(2026-02, 2026-07, 2026-11 …)별 데이터를 **스냅샷**으로 보존.
- 직전 회차 **향후계획** 대비 다음 회차 **추진현황**을 나란히 비교 표시하여,
  "계획대로 진행되지 않거나 변경된 내용"을 한눈에 파악. 변경 이력(누가/언제/무엇) 기록.

### 5.4 순기표 관리 (분기: 1월 · 4월 · 7월 · 10월)
- 주요업무와 유사한 양식이되 **서천군의 모든 사업**을 관리.
- 분기 회차별 입력·보존, 향후계획 대비 진행 변경 추적(5.3과 동일 구조).
- **정책적 주요사업 지정**: 사업별 "정책적 주요" 체크 → **별도 관리 화면**에서
  **부서별 / 읍면별 / 기간별(종료연도 기준)** 분류·집계.

### 5.5 공약사업 이행관리 *(기획실 핵심)*
- 군수 **공약 → 단위사업** 매핑, 담당 부서·팀 지정.
- 이행상태(정상추진/일부추진/지연/완료), **이행률(%)**, 분기별 점검 기록.
- 공약 분야별/연차별 이행 현황 집계, 보고서 출력. (주요업무·순기표 사업과 연결 가능)

### 5.6 국도비 보조사업 · 공모사업 관리 *(기획실 핵심)*
- 공모사업 **신청 → 선정/미선정 → 교부 → 집행** 단계 관리.
- 항목: 공모기관(부처/도), 사업명, 신청액, 선정액, **재원 매칭(국/도/군 비율)**, 기간, 담당.
- 확보 실적(선정률·확보액) 집계, 부서별/분야별 비교, 차년도 공모 캘린더.

### 5.7 인구·지방소멸 대응 사업 관리 *(서천 특화)*
- **지방소멸대응기금** 등 인구감소 대응 사업을 별도 태깅·관리.
- 기금 투자계획 대비 집행, 사업 효과(인구·정주여건 지표) 연계, 읍면별 배분 현황.

### 5.8 성과관리 · 평가 대응
- 사업/시책별 **성과지표(목표치·실적치·달성률)** 등록·관리.
- 정부업무평가·자체평가 대응 자료 연계(지표 추이, 우수사례), 연차 비교.

### 5.9 사업비 · 재원 관리
- 모든 사업에 **재원별(국/도/군/기타) 사업비** 입력, 연차별·예산구분(본예산/추경) 관리.
- 집행률(예산 대비 집행) 관리(선택), 재원별·부서별·읍면별 사업비 집계.

### 5.10 업무 일정 · 알림
- 연간 일정 등록: 보고회(2·7·11월), 순기표(1·4·7·10월), 공모 마감, 공약 점검.
- 작성 **마감 알림** 및 **부서별 제출/미제출 현황** 모니터링(서무 독려), 대시보드 위젯.

### 5.11 보고서 · 자료 출력
- 입력 데이터를 표준 양식으로 **HWP(한글)/엑셀/PDF 내보내기** (공무원 보고 실무 필수).
- 보고회 발표자료·순기표·공약 이행 보고서 자동 취합/출력, 필터 조건별 리스트 다운로드.

### 5.12 첨부 · 이미지 자료 관리
- 위치도·현장사진 등 **이미지 업로드·미리보기**, 허용 형식(jpg/png/pdf)·용량 정책,
  항목(정책/주요업무/순기표/공약/공모)별 첨부 연결.

## 6. 데이터 모델 개요

### 6.1 핵심 엔터티 및 관계
```
사용자(User) ── 소속 ──> 부서(Dept) ── 팀(Team)
정책(Policy) ── 분류 ──> 유형(Type)·분야(Field)
정책(Policy) ──< 의견(Comment)/사업제안(Idea)
주요업무(MajorTask) ──< 회차스냅샷(ReportSnapshot: 2·7·11월)
순기표(CycleItem) ──< 분기스냅샷(QuarterSnapshot: 1·4·7·10월)
순기표(CycleItem) ── 주요사업플래그 ── 읍면(Town)·종료연도(EndYear)
공약(Pledge) ──< 공약단위사업 ── 사업(연결)
공모사업(Grant) ── 재원매칭(국/도/군) ── 단계(신청/선정/집행)
성과지표(KPI) ── 사업/시책 연결 ── 목표·실적
사업비(Budget) ── 재원구분(Fund)·연차·예산구분
모든 항목 ──< 첨부파일(Attachment: 이미지/문서)
공통코드(Code): 부서·팀·읍면·유형·분야·재원·상태
```

### 6.2 공통코드·이력
- 4장 기준정보를 코드 테이블로 일원화.
- 회차/분기 **스냅샷**과 **변경 이력**(생성·수정·삭제, 작성자·일시)으로 추적성 보장.

  "공약·공모·기금이 계획대로 가는지" 비교해 정책 우선순위 판단 근거로 사용.

## 8. 비기능 요구사항
- **보안/접근통제**: 군청 내부망 운영 전제, 로그인·세션, 권한 기반 접근통제(RBAC),

- **백업/복구**: 정기 백업 및 복구 절차.
- **사용성/접근성**: 20명 규모에 맞는 직관적 UI, 드롭다운·자동완성, 웹 접근성 고려,
  표준 브라우저 지원, 향후 모바일 열람 고려.

## 9. 기술 스택 / 아키텍처 추천 (근거 포함)

> 전제: **사용자 약 20명, 내부망 중심, 소규모 운영**. 운영·유지보수 부담 최소화 우선.
> 아래는 추천안이며 군청 표준·보안 정책에 맞춰 확정한다.

### 9.1 추천 아키텍처 — 웹 기반 3-Tier
| 계층 | 추천 | 근거 / 대안 |
|------|------|-------------|
| 프론트엔드 | React(SPA) + UI 라이브러리 | 대시보드·표 입력 생산성 / 대안: Vue |
| 백엔드 | 검증된 웹 프레임워크(Spring Boot/Django/Node 택1) | 인력·유지보수 기준 / RBAC·파일·HWP·엑셀 출력 지원 |
| 데이터베이스 | PostgreSQL(또는 MySQL) RDB | 사업비·재원 집계와 관계형 분석에 적합 |
| 파일 스토리지 | 서버 파일시스템 또는 사내 스토리지 | 이미지·문서 저장, 백업 연계 |
| 출력 | HWP/엑셀/PDF 생성 라이브러리 | 행정 보고 실무 필수 |
| 배포 | 단일 사내 서버(필요 시 컨테이너) | 소규모 트래픽, 내부망에 충분 |

### 9.2 핵심 구현 방향
- **인증/권한**: 로그인 + RBAC(관리자/중간관리자/일반), 부서·서무 속성 반영.
- **회차/분기 스냅샷**: 데이터 모델 수준에서 버전 보존 → 변경 추적 보장.
- **공통코드 기반 분류**: 유형·분야·읍면·재원을 코드로 관리해 확장성 확보.
- **연계 설계**: 정책↔공약↔공모↔주요업무/순기표↔성과지표를 사업 단위로 연결.

### 9.3 검토 트레이드오프
- 자체 구축(맞춤·초기개발 필요) vs 상용 협업툴 조합(빠르나 보고회·순기표·공약/공모 특수
  양식·변경추적·HWP 출력 구현 한계). → **보고회·순기표·기획실 특화 요구**가 크므로
  **자체 구축형 권장.**

|------|--------|------|
| 1. 기반 | 로그인·권한(3단계)·부서/팀·**공통코드(읍면·분야·유형·재원)**·사용자 관리 | 토대 |
| 2. 정책 | 정책 아카이브(시행/구상)+분류+검색, 의견·사업제안 | 협업 핵심 |
| 3. 주요업무 | 보고회 양식(13항목+참고자료)+회차(2·7·11월) 비교 | 보고 디지털화 |
| 4. 순기표 | 순기표(전 사업)+정책적 주요사업+부서/읍면/종료연도 관리 | 분기 운영 |
| 5. 기획실 연계 | 공약 이행·국도비 공모·지방소멸대응기금·성과관리 | 기획실 핵심 |
| 6. 대시보드·출력 | 유형/읍면/재원별 사업비·공약 이행률 등 시각화, HWP/엑셀/PDF 출력, 알림 | 의사결정 지원 |

> 연간 일정 연계: 보고회(2·7·11월)·순기표(1·4·7·10월) 일정에 맞춰 3~4단계 우선 가동.
